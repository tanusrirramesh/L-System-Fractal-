 L System Fractal  Pattern generator
 This project is a Python application that generates L-system patterns. Resources used are Python, Tkinter for interface and Turtle graphics for visualization. User can initialize the number of iterations and rules for the pattern generation.
 Features of the project:
 Turtle for graphics.
 Tkinter for GUI.
 Custom user defined iterations and rules.
 CREATE button to generate the desired pattern.
 Working:
 First we define a axiom, which is a initial value of a string and the first instruction before any rules are applied. In this "F" is used as an axiom.
 In this project: (F)-move forward
                  (+)- turn 90 degrees to right
                  (-)- turn 90 degrees to left
User defines the rules and number of iterations.
After clicking the CREATE button the desired pattern is generated.
